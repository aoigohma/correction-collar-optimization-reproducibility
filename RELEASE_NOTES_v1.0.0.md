# v1.0.0

First public reproducibility release for the manuscript:

**Gohma A, Ue Y, Miyawaki A, Monai H. _Image-Based Correction-Collar Optimization over Time in In Vivo Two-Photon Microscopy._**

This release includes:

- compact analysis-ready MATLAB datasets for Figures 1–4;
- released source-data workbooks and supplementary-table workbooks;
- MATLAB scripts for complete numerical reproduction of the reported analyses;
- shared fitting, statistical, and plotting utilities;
- verified key numerical outputs;
- validation scripts comparing regenerated outputs with verified references;
- main-figure data-panel generation scripts;
- Supplementary Figure S1–S6 generation scripts; and
- documentation of analysis definitions, data structure, figure generation, and software requirements.

The compact repository does not contain the original OIR acquisition files or the representative raw fluorescence-image assets used in Figure 1C. TIFF-converted images used for image analysis are available from the corresponding author upon reasonable request.

Archived Zenodo record for this release: https://doi.org/10.5281/zenodo.22885339.
