# Analysis-ready data

Place the released/generated compact MAT files in this folder:

```text
Figure1_analysis_ready.mat
Figures2to4_analysis_ready.mat
```

The metadata CSVs in this directory summarize their experiment IDs, scan ranges, analysis windows, and segment structure.

The MAT files are generated by:

```text
code/builders/build_Figure1_analysis_ready.m
code/builders/build_Figures2to4_analysis_ready.m
```

The compact datasets contain normalized measured Peak-F profiles and essential metadata. Derived values such as θopt, R², W95, relative fitted score, and DiffMAD are intentionally recomputed by the reproduction scripts.
