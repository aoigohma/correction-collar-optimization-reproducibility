# Source-data workbooks

These workbooks correspond to the final figure/source-data records and supplementary tables used for manuscript reporting and validation.

They are **not inputs** to the numerical reproduction scripts. The reproduction scripts start from the compact analysis-ready MAT files and recalculate the derived results independently.


Historical LME sheets in `SourceData_Figure4.xlsx` and `Supplementary_TableS2_Figure4_LME.xlsx` are preserved unchanged for provenance; they are **not part of the current no-LME manuscript**.
