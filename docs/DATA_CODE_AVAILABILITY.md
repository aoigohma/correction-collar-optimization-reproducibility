# Data and code availability — current no-LME manuscript

The text below applies **only after** the no-LME v1.0.1 GitHub release has been archived on Zenodo and its new version-specific DOI has been confirmed. Do not cite the historical v1.0.0 DOI (10.5281/zenodo.22885339) as if it described the current no-LME archive.

> **Data and code availability.** Analysis-ready datasets, source-data workbooks underlying the figures and supplementary tables, mouse-level data used in the reported analyses, verified reference outputs, and MATLAB code for reproducing the analyses reported in this manuscript are available in the no-LME repository release (version 1.0.1) at Zenodo (DOI: **[NEW V1.0.1 DOI — insert after archiving]**). The development repository is available at https://github.com/aoigohma/correction-collar-optimization-reproducibility. The deposited code includes scripts for curve fitting, estimation of the optimal correction-collar angle and W95, calculation of relative fitted scores and DiffMAD, statistical analyses included in the current manuscript, validation, and generation of the data-driven figure panels. Earlier exploratory mixed-effects-model code and outputs are retained as historical materials and are not part of the analyses reported in this manuscript.
>
> The TIFF-converted images used for image analysis are available from the corresponding author upon reasonable request. The compact repository does not contain the original OIR acquisition files or the representative fluorescence-image assets used in Figure 1C; neither is needed to reproduce the reported numerical analyses. The availability of the original OIR files has not been established.
